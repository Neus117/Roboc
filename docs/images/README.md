# 截图目录

README 引用了以下三张图，放入同名的 PNG 即可显示：

| 文件名 | 内容 | 建议 |
|---|---|---|
| `context-menu.png` | 资源管理器右键展开 Roboc 子菜单 | 要能看清六项的图标 |
| `progress.png` | 复制进度窗，最好有速度曲线与剩余时间 | 大文件或海量小文件时截 |
| `settings.png` | 设置窗口，选中一个开关让说明区显示出来 | 深色主题 |

**建议**：宽度不超过 1200 px，PNG 格式，**深色主题**——本程序的自绘配色在深色下更能体现设计。

截图里**不要包含真实的文件路径或文件名**，除非你不介意公开。
