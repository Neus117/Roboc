# Roboc 弹窗清单

用于目视验收与后续调整。**全部弹窗均为自绘**，共用 [视觉规范](视觉规范.md) 的字号、配色、圆角与按钮样式；无一使用系统 `MessageBox`。

**通用规则**：正文与按钮 10 pt ／ 深色主题标题栏 ／ DWM 圆角 ／ 文字居中（下表"居中"列全部为 ✓）。

---

## 七、排版改动（2026-10-12 第二轮）

### 根本原因

**正文逐行居中（`DT_CENTER`），每行宽度不同 → 左边缘不同 → 列不可能对齐。**

之前用全角空格手工凑宽度，三行分别是 23 / 25 / 22 单位，**居中后彼此错位**。

### 解法：让每行总宽完全相等

新增三个工具：

| 函数 | 作用 |
|---|---|
| `DisplayWidth(text)` | 计算显示宽度：汉字 / 全角 = 2，ASCII = 1 |
| `PadValue(value, units)` | 在给定宽度内**右对齐**数值 |
| `StatRow(label, value)` | 标签补到 12 单位 + 数值右对齐在 10 单位内 = **恒定 22 单位** |

**运行时计算，不是写死空格**——数值会随数量变长（`4 个` → `10000 个`），写死的空格在第一次遇到四位数时就会错位。

### 逐项改动

| 弹窗 | 改动 |
|---|---|
| **彻底删除** | 三行统计改用 `StatRow`，全部 22 单位 |
| **粘贴冲突** | ① 去掉 `内容完全相同` 的前导全角空格<br>② `内容完全相同` → **`内容相同`**（与 `内容不同`／`类型不同`／`涉及大小` 同为 4 字，对仗）<br>③ 重新配平标签与数值间空格<br>④ `将新增文件`／`将新增文件夹`／`将合并` 三行同样改用 `StatRow` |

### 排布实测

```
删除弹窗                             冲突弹窗
[22] 包含文件　　      4 个          [22] 内容相同　　  8 个文件
[22] 包含文件夹　      0 个          [22] 内容不同　　  3 个文件
[22] 共占空间　　  11.44 GB          [22] 类型不同　　      0 个
[22] 包含文件　　  10000 个          [22] 涉及大小　　  22.88 GB
[22] 包含文件夹　    250 个
```

**数值变长后仍为 22 单位，列不会错位。**

## 八、死代码清理与安全修复

### 删除 `ConfirmEmptyBin`

**不可达**：菜单命令 `reclaim --gui-errors` 不含 `--empty`，而该对话框只在 `--empty` 分支内调用。已删除。

### 顺带发现并修复的安全漏洞

```csharp
// 原文
if (!args.Flag("--yes") && !args.Flag("--gui-errors"))
{
    Console.Error.WriteLine("roboc: 清空回收站不可恢复，需要 --yes 确认");
    return 2;
}

if (args.Flag("--gui-errors") && !ConfirmEmptyBin(items.Count, totalBytes)) { return 0; }
```

**它接受 `--gui-errors` 替代 `--yes`**，理由写在注释里——"菜单路径会显示确认对话框"。

**但菜单从不传 `--empty`**，所以那个对话框永远不会出现，**这个豁免等于"无确认清空回收站"**。

现改为 `--yes` 是唯一途径：

```
reclaim --empty            →  退出码 2，"需要 --yes 确认"，回收站未被清空 ✓
```
